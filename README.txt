MAAHI / SADAF BIRTHDAY WEBSITE ♡
This version has NO personal photos. It uses cute bear, hearts, flowers and pink decorations.

Files to upload together:
- index.html
- style.css
- script.js

To preview on phone:
1. Download and extract this ZIP.
2. Open the folder in Acode.
3. Open index.html and tap Preview.
4. To publish with GitHub Pages, upload all three files to the same repository folder.

Text is in Hinglish and written as a brother's birthday message to his sister.
